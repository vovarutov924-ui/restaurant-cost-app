# CostChef: Калькулятор себестоимости с ИИ-анализом

**Автор:** Владимир Рутов
**Дата создания:** Ноябрь 2024

Приложение для расчета себестоимости блюд и интеграции с локальной нейросетью (Qwen 2.5) для анализа меню.

## Технологии:
* Python (PySide6)
* SQLite
* Unsloth / Qwen 2.5 (обучение модели)
* LM Studio (локальный запуск ИИ)
